# Omkar Shinde — Portfolio

Portfolio website of Omkar Shinde, video editor and videographer.

A single static page: open `index.html` in a browser, or deploy the folder to any static host (Netlify, GitHub Pages, Cloudflare Pages).

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: markup, styles and script |
| `Video-67998.mp4` | Showreel video |
| `showreel-poster.jpg` | Showreel thumbnail shown before it plays |
| `logo-bg.jpg` | Logo artwork used as the site background |

## Editing content

Everything the page shows comes from the `SITE`, `PROJECTS`, `SKILLS`, `TOOLS` and `SERVICES` blocks near the top of the `<script>` in `index.html`: contact details, showreel, portraits and project links.
